# 将 GitHub 仓库设为「私有」（隐藏仓库）

「隐藏」在 GitHub 上指 **Private**：只有你与受邀协作者可见，不会在公开资料中展示代码。

## 操作步骤（网页）

1. 打开 **GitHub** 并登录。
2. 进入该仓库主页。
3. 点击 **Settings（设置）**。
4. 左侧拉到最底 **Danger Zone（危险区域）**。
5. 点击 **Change repository visibility** → **Change visibility**。
6. 选择 **Private**，按提示输入仓库名确认。

## 说明

- 免费账号也可使用 **私有仓库**（有数量/协作者等限制，以 GitHub 当前政策为准）。
- 若仓库已关联 **Vercel** 等部署，改为私有后一般仍可部署，需在对应平台重新授权或确认权限。
- 历史提交若曾包含敏感文件，仅改私有不能从 Git 历史中抹除；需用 `git filter-repo` 等工具清理（另行处理）。
